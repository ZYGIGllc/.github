# Contributing (Zygig)

This repository holds org-wide community health files for [ZYGIGllc](https://github.com/ZYGIGllc).

## Public work

For the public [ToolsFree](https://github.com/ZYGIGllc/ToolsFree) tools, follow that repo’s CONTRIBUTING.md (client-side only, no data collection).

## Private product work

Zygig product and store-shipping repositories are private. Contributors with org access use short-lived branches (`feat/…`, `fix/…`, `chore/…`), open a pull request to `main`, and keep CI green. Do not push directly to `main`. Prefer conventional commits: `feat:`, `fix:`, `chore:`, `docs:`.

New private app repositories are created from the org’s private app template (org members only). Shared store automation lives in a private hub repository (org members only).
