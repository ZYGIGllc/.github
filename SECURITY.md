# Security Policy

## Supported versions
Zygig ships consumer apps from private product repositories under `ZYGIGllc`. Only the latest production release of each app is supported for security fixes.

## Reporting a vulnerability
Email **security@zygig.com** (or the account owner on file) with:
- affected product / repo
- description and impact
- reproduction steps or proof-of-concept

Please do **not** open a public GitHub issue for security reports.

We aim to acknowledge within 3 business days.
